# FINAL OUTPUT CONTRACT

## ÉXITO

Únicamente:

```text
SCRIPT_PACKAGE:
{
  ... JSON válido completo ...
}

ELEVENLABS_V3_TEXT:
<texto final>
```

No añadir:
- análisis;
- QA;
- estados;
- links;
- citas;
- explicación;
- notas;
- razonamiento;
- comentarios.

## SCRIPT BLOQUEADO

Únicamente:

`OUTPUT_BLOCKED`

## VOICE BLOQUEADO

Únicamente:

```text
SCRIPT_PACKAGE:
<JSON válido completo>

VOICE_TEXT_BLOCKED
```
