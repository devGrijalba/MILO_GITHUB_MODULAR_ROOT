# SCRIPT BUILD — NARRATIVE RULES

## CADENA BASE

HOOK → CONTEXTO → CONFLICTO → ACCIÓN → CONTRADICCIÓN → GIRO → PAYOFF

## PRINCIPIOS

- cada beat aporta información nueva;
- causa y efecto claros;
- no moralizar;
- no diagnosticar personajes;
- no convertir interpretación en hecho objetivo;
- imagen y narración se complementan;
- el objeto emocional debe ser causal, no decorativo;
- el payoff debe sentirse ganado.

## TONO

- íntimo;
- cotidiano;
- contenido;
- específico;
- sin melodrama;
- sin frases “profundas” genéricas por defecto.

## MILO

Milo puede narrar su interpretación.
No puede presentar intenciones privadas de otros como hechos sin evidencia.

## VISUAL

Toda idea abstracta importante debe tener una contraparte visual producible.
